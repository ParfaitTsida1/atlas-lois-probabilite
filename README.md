# Atlas des lois de probabilité

Application web en français pour explorer les lois de probabilité : caractéristiques, graphiques, calculateur de probabilités et de quantiles, simulations et exemples concrets.

- Lois discrètes : Bernoulli, binomiale, géométrique, Poisson, hypergéométrique, uniforme, Pascal
- Lois continues : uniforme, exponentielle, normale, log-normale, gamma, bêta, khi-deux, Student, Fisher

Le site est un seul fichier `index.html`, sans dépendance : il s'ouvre directement dans un navigateur.
